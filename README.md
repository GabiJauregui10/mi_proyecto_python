# Mi Proyecto Python 🐍

Este es mi primer proyecto en Python utilizando entorno virtual y Git.

## 📌 Descripción
El proyecto consiste en una aplicación básica en Python que servirá como base para futuros desarrollos.

## 🧠 Entorno virtual
Se creó un entorno virtual para aislar las dependencias del proyecto.

Crear entorno virtual:
python -m venv venv

Activar entorno virtual (Windows):
venv\Scripts\activate

## 📦 ¿Qué es pip?
pip es el gestor de paquetes de Python. Permite instalar librerías externas necesarias para el proyecto.

Ejemplo de instalación:
pip install nombre_paquete

## ▶️ Ejecutar el proyecto
Una vez activado el entorno virtual:

python app.py

## 🛠️ Tecnologías usadas
- Python
- Git
- Entorno virtual (venv)
